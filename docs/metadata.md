## siteprobe

**Description:** Security headers checker and website scanner with about 100 security, SEO and speed checks. Zero dependencies, fetch only: runs on Node 20+, Cloudflare Workers, Deno and Bun. CLI and typed API with scores and fix hints.

**Topics:** `security-headers`, `security-scanner`, `csp`, `hsts`, `seo`, `website-audit`, `lighthouse-alternative`, `cli`, `typescript`, `cloudflare-workers`, `deno`, `bun`, `nodejs`

## redirect-lint

**Description:** Redirect chain checker for Netlify and Cloudflare Pages _redirects files, CSV (including WordPress Redirection exports) and JSON. Finds loops, chains, duplicates, shadowed rules and clashes with live pages, and flattens chains to one hop. Zero dependencies.

**Topics:** `redirects`, `redirect-checker`, `redirect-chain`, `netlify`, `cloudflare-pages`, `wordpress`, `seo`, `linter`, `csv`, `cli`, `typescript`, `nodejs`

## static-preflight

**Description:** Broken link checker and preflight for static site builds. Checks internal links, images and assets, SEO basics, share cards, icons, JSON-LD, redirects and old URLs in one zero-dependency pass. Works with Next.js export, Astro, Eleventy, Hugo and any HTML output.

**Topics:** `broken-links`, `link-checker`, `static-site`, `seo`, `preflight`, `open-graph`, `json-ld`, `nextjs`, `astro`, `eleventy`, `hugo`, `ci`, `cli`, `typescript`, `nodejs`

## translation-facts

**Description:** Translation quality assurance for i18n JSON files. Checks that numbers, prices, percentages, URLs, emails, {placeholders} and terms to keep survive machine or AI translation. Works on i18next and next-intl style files. Zero dependencies, CLI and API.

**Topics:** `translation`, `i18n`, `l10n`, `localization`, `qa`, `i18next`, `next-intl`, `placeholders`, `machine-translation`, `ai-translation`, `linter`, `cli`, `typescript`, `nodejs`

## gpx-privacy

**Description:** Edit a GPX file to make it safe to share. Trims the first and last 500 m of a track, simplifies the line, computes distance, climb and duration, and writes a minimal clean GPX file. Library and CLI, one runtime dependency.

**Topics:** `gpx`, `gps`, `privacy`, `strava`, `cycling`, `running`, `trim`, `simplify`, `gpx-parser`, `cli`, `typescript`, `nodejs`

## mcp-guardrails

**Description:** MCP security for servers that let AI agents change data. Dry run and confirm, signed preview tokens, optimistic concurrency, revision undo and errors that teach the agent. Works with the official MCP TypeScript SDK; the core runs on Node 20+ and edge runtimes.

**Topics:** `mcp`, `model-context-protocol`, `mcp-server`, `ai-agents`, `llm`, `guardrails`, `ai-safety`, `dry-run`, `optimistic-concurrency`, `json-merge-patch`, `undo`, `typescript`, `nodejs`

## safe-html-pdf

**Description:** Playwright PDF renderer for untrusted or AI-written HTML. JavaScript and network off, only the files you serve are loaded, hard limits on time and concurrency, and a layout lint for overflow, text outside the page and broken images. Library and CLI.

**Topics:** `pdf`, `html-to-pdf`, `playwright`, `chromium`, `headless`, `untrusted-html`, `ai-generated`, `pdf-generation`, `slides`, `security`, `cli`, `typescript`, `nodejs`

## viewport-qa

**Description:** Responsive design testing CLI and library. Loads a page in Chromium at widths from 390 to 3840 and measures horizontal overflow, clipped text, layout shift, low-resolution images and inconsistent insets and radii, with selectors and numbers. Built on Playwright.

**Topics:** `responsive-design`, `responsive-testing`, `layout`, `qa`, `playwright`, `chromium`, `layout-shift`, `cls`, `css`, `design-qa`, `cli`, `typescript`, `nodejs`

## active-window-sessions

**Description:** Turn active-win and get-windows readings into clean time segments per app and per website. Merges short gaps, drops blips, cuts at the last input when idle, ignores system UI and totals usage. Includes macOS permission helpers for Electron apps.

**Topics:** `active-win`, `active-window`, `get-windows`, `time-tracking`, `app-usage`, `activity-tracking`, `screen-time`, `idle`, `electron`, `macos`, `typescript`, `nodejs`
